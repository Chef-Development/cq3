# Difficulty retargeted for a 75% player

Generated by `ACC=0.75 npm run retarget` (`tests/balance/retarget.run.ts`), 150 runs per step. The defaults are set
for a 75% player. This keeps the same curve (a gentle Act 1, a step up in Act 2, the Boar King as the
real test, with the gear found on the way) for a player of the measured accuracy (the gear panel shows it).

| Act | Target | Result | Enemy HP and attack | hpMult | atkMult |
|---|---|---|---|---|---|
| 1 | first-try clear: 99% | 99% | x1.19 | 1.19 | 1.19 |
| 2 | first-try clear: 87% | 87% | x0.98 | 1.18 | 5.89 |
| 3 | Boar King first fight won: 70% | 74% | x1.02 | 2.04 | 7.34 |

To try it on the phone: gear panel > Export > Paste JSON, and paste:

```json
{"tuning":{"acts":[{"hpMult":1.19,"atkMult":1.19},{"hpMult":1.18,"atkMult":5.89},{"hpMult":2.04,"atkMult":7.34},{"hpMult":3.4,"atkMult":8},{"hpMult":5.3,"atkMult":13.5},{"hpMult":5.6,"atkMult":11.5},{"hpMult":6.2,"atkMult":13.5},{"hpMult":6.4,"atkMult":13.8},{"hpMult":7,"atkMult":15}]}}
```

To make it the default, put the hpMult / atkMult values into `src/data/greenmarch.ts`, set `TYPICAL_ACCURACY` in
`src/core/bot.ts` to 0.75, and re-run `npm test` and `npm run balance`.
